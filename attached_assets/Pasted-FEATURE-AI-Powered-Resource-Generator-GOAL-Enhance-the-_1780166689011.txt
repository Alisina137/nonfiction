FEATURE: AI-Powered Resource Generator

GOAL

Enhance the Resources step by adding intelligent resource generation that automatically fills:

- URL
- Label
- Note for Generation

based on:

1. All previous book-building steps
2. Selected Category
3. Selected Priority
4. Selected Use For options

The user can then review/edit and click "Add Link" to save the resource.

====================================================
NEW UI
====================================================

Add a button beside "Add Link":

[✨ Generate Resource]

====================================================
BOOK CONTEXT
====================================================

When generating resources, the AI must use all available project context:

- Research
- Analysis
- Competitor Books
- Market Findings
- Book Title
- Subtitle
- Proposed Book
- Author Persona
- Audience
- Book Positioning
- Core Topics
- Pain Points
- Outline (if available)
- Any previously added resources

The generated resource must directly support the current book project.

====================================================
RESOURCE SETTINGS
====================================================

Use current form selections:

{
  category,
  priority,
  useFor
}

====================================================
AI GENERATION OUTPUT
====================================================

Generate ONLY valid JSON:

{
  "url": "",
  "label": "",
  "note": ""
}

Requirements:

- Real resource
- High relevance
- High credibility
- Specific URL when possible
- Never generate fake links
- Never generate placeholder URLs
- Never generate generic homepages when a direct page exists

====================================================
AUTO FILL
====================================================

After successful generation:

form.url = result.url
form.label = result.label
form.note = result.note

====================================================
SMART FILTERING
====================================================

Never recommend:

- Duplicate resources
- Already-added resources
- Broken links
- Low-authority websites
- Spam content
- Irrelevant sources

Prefer:

- Universities
- Government agencies
- Research institutions
- Trusted journals
- Recognized experts
- Established publishers
- Existing competitor books from Analysis
