ANALYSIS STEP – AMAZON BESTSELLER ENGINE FIXES & IMPROVEMENTS

The Analysis step currently has multiple issues that must be fixed.

GOAL

When the user clicks "Search Bestsellers", the system should return clean, deduplicated, high-quality book results with complete metadata and cover images.

====================================================
ISSUE 1: MISSING BOOK COVER IMAGES
==================================

Problem:

Many results display "No cover" even though the book has a cover on Amazon.

Required Fix:

1. Use Rainforest API as primary source.

2. Always attempt to fetch:

   * cover image
   * title
   * author
   * rating
   * review count
   * price
   * BSR rank
   * publication date

3. If Rainforest image exists:
   display it.

4. If Rainforest image missing:
   try Scale SERP.

5. If Scale SERP missing:
   try Open Library.

6. If all sources fail:
   display a professional placeholder cover.

Never leave broken image containers.

Add image loading states and fallback handling.

====================================================
ISSUE 2: EXPAND DETAILS SHOWS NO DATA
=====================================

Problem:

User clicks "Expand Details" but many cards contain empty information.

Required Fix:

Expand Details must show:

BOOK INFORMATION

* Full title
* Subtitle
* Author
* Publisher
* Publication date
* ASIN
* ISBN
* Language
* Page count
* Format

AMAZON PERFORMANCE

* Rating
* Total ratings count
* Bestseller rank
* Category rankings

MARKET INSIGHTS

* Estimated competition score
* Review velocity
* Opportunity score

DESCRIPTION

* Full description
* Expand/collapse functionality

KEYWORDS

* Extract important keywords

PREVIEW

* Cover image
* Large image preview

If data is unavailable:

show:

"Data unavailable from source"

instead of empty fields.

Never show blank sections.

====================================================
ISSUE 3: DUPLICATE BOOKS
========================

Problem:

The same book sometimes appears multiple times.

Required Fix:

Before rendering results:

Deduplicate by:

1. ASIN (highest priority)
2. ISBN
3. Amazon URL
4. Normalized title

Normalize titles by:

* lowercase
* trim spaces
* remove punctuation
* remove edition markers
* remove workbook markers

Examples:

"ADHD Workbook"
"ADHD Workbook: Revised Edition"

should be considered potential duplicates.

Only keep the strongest result.

Priority:

Rainforest > Scale SERP > Open Library
