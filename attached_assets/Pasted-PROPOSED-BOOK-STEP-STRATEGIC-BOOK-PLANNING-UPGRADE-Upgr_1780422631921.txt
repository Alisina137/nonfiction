PROPOSED BOOK STEP — STRATEGIC BOOK PLANNING UPGRADE

Upgrade the Proposed Book step into a strategic publishing engine that automatically builds the best book concept before outline generation.

IMPORTANT

Use ALL available project data when generating suggestions:

- Research
- Analysis
- Market Analysis
- Competitor Books
- Resources
- Findings
- Book Title
- Subtitle
- Topic
- Genre
- Author Persona
- Writing Sample
- Target Audience
- Reader Pain Points
- Reader Psychology
- Transformation Promise
- Market Gap
- Bestseller DNA
- Focus Topics
- Positioning Statement
- Core Promise
- Core Thesis
- Unique Mechanism

Do NOT generate generic outputs.

Every recommendation must be niche-specific and derived from the project's actual data.

================================================
AUTO GENERATE STRATEGIC BOOK PLAN
================================================

Add a button at the top of the Proposed Book page:

✨ Generate Strategic Book Plan

When clicked, automatically generate and populate:

1. Recommended Structure
2. Structure Explanation
3. Signature Framework
4. Chapter Blueprint Components
5. Book Flow Preview
6. Competitive Differentiation
7. One-Sentence Book Pitch
8. Book Concept Score

Store all generated values in project state so downstream steps can use them.

================================================
FEATURE 1 — AI RECOMMENDED STRUCTURE
================================================

Add a new section:

Recommended Book Structure

Generate:

- Structure Name
- Structure Type
- Confidence Score
- Reasoning

Example:

Recommended Structure:
Blueprint-Based How-To

Structure Type:
Implementation Roadmap

Confidence:
9.4 / 10

Reasoning:
Competitor analysis and reader intent indicate that step-by-step implementation books outperform conceptual books in this niche.

Add:

[ Regenerate Structure ]

If the user manually changes the structure dropdown, update this section accordingly.
